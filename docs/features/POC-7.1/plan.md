## Contract changes
- boundary: new `POST /api/v1/auth/otp/request` and `OtpRequestResponse`; `openapi.json` regenerated by `uv run python -m app.cli --export-openapi`.
- dependency: `pwdlib[argon2]` runtime (rule C2, approved 2026-11-04) via `uv add` (never hand-edit `uv.lock`, T3; `pyproject.toml` is ask-first).
- data: none (no migration; `otpHash`, `otpSalt`, `otpExpiresAt` exist). `otpSalt` is no longer written.
- internal API 7.2 and 7.3 will call: `OtpService.verify_code`, `app/core/hashing.py` (`hash_secret`, `verify_secret`), `get_otp_service`.

- files: `tests/e2e/test_db_session.py`, `tests/e2e/test_http_auth_helper.py`, maybe `tests/conftest.py`, `docs/RUNBOOK.md` (the "only stub routes prove it" line). Find each cause first (run with the dev `.env`, then with none); fix the test or the code, never the assertion's strength (B3). If (1) turns out to be a real leak outside local, stop and report (B4).
- test: the two tests themselves, run in the repo (developer `.env` present) and from a fresh `git worktree` of the branch, which has no `.env`; the worktree is removed afterwards. The `.env` is never moved or edited (protected path).

### R2 — hashing seam and ADR (S)
- files: `pyproject.toml` + `uv.lock` (`uv add "pwdlib[argon2]"`), `app/core/hashing.py` (`hash_secret(secret) -> str`, `verify_secret(secret, hash) -> bool`; a `PasswordHash((Argon2Hasher(<OWASP minimum profile>),))` built once; both `async`, through `asyncio.to_thread`; a hash string pwdlib cannot parse verifies `False`, anything else propagates, rule D5), `docs/decisions/ADR-0028-argon2-hashing-pwdlib.md` (supersedes the password bullet of ADR-0008 ("Passwords stay bcrypt (10 rounds) with the 8 to 72 byte length check") and the scope doc's "bcrypt" for OTP; keeps ADR-0008's sha256 refresh-token bullet; states whether the 8 to 72 byte password check in `app/core/validation.py` stays for 7.3 (default: it stays, no change in 7.1); records the human-approved cost profile), a status line in `docs/decisions/ADR-0008-…md` pointing to ADR-0028, `tests/unit/test_hashing.py`.

- Verify before use (rule D4): `Argon2Hasher` parameter names and mypy typing from the installed package, not memory; if pwdlib is untyped under mypy strict, stop and report (no `type: ignore`, S3).
- test: hash verifies; two hashes of one secret differ; wrong, empty and foreign hash false; the stored string starts `$argon2id$` and holds neither input.
